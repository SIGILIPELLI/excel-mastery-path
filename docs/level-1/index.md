# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: get comfortable navigating Excel, write real formulas, format and
visualize data, look values up across sheets, and finish with a working
personal budget tracker built from scratch.

## Modules

1. [Excel Fundamentals](01-excel-fundamentals.md)
2. [Formulas & Functions Basics](02-formulas-functions-basics.md)
3. [Formatting & Conditional Formatting](03-formatting-conditional-formatting.md)
4. [Working with Tables](04-working-with-tables.md)
5. [Charts & Basic Visualization](05-charts-basic-visualization.md)
6. [Lookup Functions](06-lookup-functions.md)
7. [Logical Functions](07-logical-functions.md)
8. [PivotTables Basics](08-pivottables-basics.md)
9. [Data Validation & Cleaning](09-data-validation-cleaning.md)
10. [Project — Personal Budget Tracker](10-project-personal-budget-tracker.md)

By the end of this level you'll be comfortable navigating the Excel
interface, writing formulas with correct relative/absolute references,
formatting and charting data, looking values up with `VLOOKUP`/`XLOOKUP`,
building logic with `IF`, summarizing data with PivotTables, and cleaning
messy input — and you'll have produced a small real deliverable: a personal
budget tracker with its own formulas, formatting, and a summary chart.
