# Excel Mastery Path

A structured, module-wise Microsoft Excel training program that takes you
from the interface and your first formula to a full business reporting
system — with step-by-step workflow instructions, function cheat sheets,
and a hands-on exercise in every module.

This track is **not** about coding — it's about learning the spreadsheet
tool itself: formulas, PivotTables, Power Query, Power Pivot, VBA, and
dashboard design, as real analyst workflows.

## How the program is organized

| Level | Focus | Modules |
|-------|-------|---------|
| [Level 1 · Entry](level-1/index.md) | Interface, formulas, formatting, Tables, charts, lookups, logic, PivotTables, data cleaning | 9 topics + 1 project |
| [Level 2 · Intermediate](level-2/index.md) | Advanced formulas, PivotTable depth, dashboards, Power Query, dynamic arrays, what-if analysis, macros | 9 topics + 1 project |
| [Level 3 · Advanced](level-3/index.md) | VBA, advanced Power Query, Power Pivot, DAX, LAMBDA, financial modeling | 9 topics + 1 project |
| [Level 4 · Master](level-4/index.md) | Enterprise architecture, advanced DAX, Power BI integration, VBA applications, governance, career growth | 9 topics + 1 capstone |

## How to use this site

- Work through each level in order — later modules assume earlier ones.
- Every topic page has numbered, step-by-step instructions with menu paths
  and exact formulas spelled out — follow along inside a real workbook.
- Each topic ends with a cheat-sheet table of the key functions or shortcuts
  covered, plus an **Exercise** to practice the workflow on your own data.
- Each level ends with a project that combines everything learned in that
  level.
- Use the search bar (top of the page) to jump straight to a topic.

Start here → [Level 1 · Entry](level-1/index.md)

## What you'll need

Microsoft Excel (Microsoft 365, Excel 2021, or Excel 2019 at minimum) on
Windows or Mac. Some Level 2+ features — dynamic arrays (`FILTER`, `SORT`),
`XLOOKUP`, and `LAMBDA` — require a Microsoft 365 subscription or a recent
perpetual version; the lessons note it where a feature isn't available in
older versions.
