# Excel Mastery Path

A free, structured, module-wise Microsoft Excel training program — entry
level to master level, with step-by-step workflow instructions, function
cheat sheets, and a hands-on exercise in every module. Focused on real
analyst skills: formulas, PivotTables, Power Query, Power Pivot, DAX, VBA,
and financial modeling.

**Live site:** https://sigilipelli.github.io/excel-mastery-path/

## Contents

- **Level 1 · Entry** — interface, formulas basics, formatting, Tables, charts, lookups, logic, PivotTables, data cleaning, budget tracker project
- **Level 2 · Intermediate** — advanced formulas, PivotTable depth, dashboards, Power Query, dynamic arrays, what-if analysis, macros
- **Level 3 · Advanced** — VBA, advanced Power Query, Power Pivot, DAX, LAMBDA, financial modeling
- **Level 4 · Master** — enterprise architecture, advanced DAX, Power BI integration, VBA applications, governance, career growth
